# 多媒体：图片生成与资产

顶部导航的「多媒体」入口位于 `/multimedia`，需要浏览器登录会话。页面使用站点当前主题，通过浮动工具栏切换图片生成和我的资产。管理员可在「顶部导航」设置中控制入口显示。

## 模型与计费

工作台直接选择图片模型，无需选择分组。模型列表汇总当前用户有权访问的全部分组及已启用渠道，同名模型去重；不依赖管理员的 `AutoGroups` 配置。后台优先使用用户所属分组，其次按自动分组顺序，再按其他可访问分组名称排序匹配。实际分组仍用于权限检查和计费。渠道需要绑定到某个可访问分组，但不必为工作台单独新建分组。

支持 GPT Image、DALL·E、Gemini 原生图片生成/编辑、Imagen，以及现有图片中继适配器所支持的通用图片模型。Gemini 按渠道能力使用 `generateContent` 或兼容的聊天图片接口，支持参考图、画面比例及模型支持的分辨率。不同模型的图片数量、质量和尺寸按能力展示。聊天图片接口使用 `image_config` 传递比例与分辨率，适用于 OpenRouter 等支持此协议的上游。

模型识别结合渠道模型名、模型映射和端点配置，不再限定 GPT/DALL·E 名称。自定义图片模型名称无法自动识别时，可在「模型」中为模型配置 `image-generation` 端点，或通过模型映射指向真实图片模型。该配置用于声明能力；供应商仍需实际支持对应接口。通用模型提供基础提示词和尺寸控件，特有接口或参数需由渠道适配器处理。仅能理解图片的聊天模型及视频模型不属于图片生成模型。

同一别名在多个渠道映射到不同图片能力时，后台选择优先分组和优先级最高的兼容配置；必要时固定对应渠道，避免把 Gemini 参数发送到 GPT 等其他模型。队列执行前再次校验模型、分组权限与参数，配置变化导致不兼容时会停止执行。

图片请求使用现有的路由分发、模型限制、预扣费、结算及消费日志。浏览器会话直接使用用户资金来源，无需创建 API 令牌；不提供额外免费额度。质量、尺寸、数量和输出格式按模型能力展示，压缩率只在 JPEG/WebP 输出时生效。工作台暂不提供背景、内容审核或蒙版参数；历史作品复用设置及旧任务执行也不会再向上游提交这些参数。

生成任务保存至数据库，用户离开页面后仍会执行。每位用户最多同时保留 3 个排队/执行中的任务，每个应用实例同时执行 2 个任务。请求标识用于防止同一次提交因网络重试重复入队。执行中的任务若因进程中断超过 20 分钟，会标记为中断，不自动重发上游请求；用户应先检查消费日志再决定是否重新生成。上游生成成功但存储失败时也会明确标记，避免误认为未计费。

## 文件存储

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MULTIMEDIA_STORAGE_DIR` | `data/multimedia` | 原始图片与缩略图目录，需要应用进程读写权限 |
| `MULTIMEDIA_RETENTION_DAYS` | `30` | 文件保留天数，范围 1–3650 |

部署时为该目录挂载持久化存储。例如已有容器挂载 `/data` 时，可设置 `MULTIMEDIA_STORAGE_DIR=/data/multimedia`。多个应用实例必须使用同一个共享目录，因为任务可能由任一实例领取，资产下载也可能由任一实例响应。数据库备份应与媒体目录一同规划；仅备份数据库不能恢复图片。

图片原件和缩略图均经鉴权接口读取，不作为公开静态资源暴露。资产查询、引用、预览、下载和删除均校验归属及有效期。资产默认保留 30 天；每分钟清理一批过期或已删除文件。参考图支持 PNG/JPEG/WebP，单张上限 32 MB，服务端实际解码校验格式和像素上限。Gemini/聊天图片请求的参考图总大小上限为 64 MB。

我的资产支持类型筛选、分页、全选当前页、ZIP 批量下载、确认后删除，以及回填参考图。我的作品使用与资产库一致的图片栅格：手机两列，桌面三列，批量生成的图片分别展示。排队或生成中显示没有文字及百分比的渐变骨架图，失败或中断后停止动效，成功后替换为实际图片；系统开启减少动态效果时禁用动效。作品卡片支持查看任务状态、展开错误详情、预览和下载图片、复用提示词及设置。图片过期或删除后不再出现在资产库与作品预览中。

## 验证

```sh
go test ./controller ./service -run TestMultimedia -count=1
cd web
bun test src/features/multimedia/__tests__
bun run typecheck
bun run build
```

后端集成测试通过本地模拟上游验证实际图片中继、用户余额扣费和图片落盘，不调用付费服务。
